# Customer Churn Analysis & Power BI Dashboard

An end-to-end customer churn analysis project using Python, Pandas, and Microsoft Power BI to identify customer churn patterns and generate actionable business insights.

## 📊 Project Overview

Customer churn is a major challenge for subscription-based businesses. This project analyzes customer data to understand churn behavior across different customer segments and service characteristics.

The project covers the complete data analysis workflow:

**Data Cleaning → Exploratory Data Analysis → DAX Analysis → Dashboard Development → Business Insights**

## 🎯 Objectives

- Analyze overall customer churn.
- Identify factors associated with customer churn.
- Compare churn across contract types.
- Analyze churn by internet service.
- Study payment method and technical support patterns.
- Examine the relationship between customer tenure and churn.
- Build an interactive Power BI dashboard for decision-making.

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook
- Microsoft Power BI
- DAX
- Excel
- CSV
- Data Visualization
